# Redis 入门

## 数据类型

Redis 是一个开源的内存键值数据库，支持多种数据结构。最常见的数据类型包括：

- **String**：最基本的键值对，可存储字符串、整数或浮点数。
- **Hash**：适合存储对象，例如用户信息。
- **List**：按插入顺序排序的字符串列表，可实现队列或栈。
- **Set**：无序且不重复的字符串集合。
- **Sorted Set**：每个成员关联一个分数，按分数排序。

## 缓存场景

Redis 最常用的场景之一是作为缓存层。将热点数据放入内存，可以显著降低数据库压力并加快响应速度。缓存时通常需要设置过期时间，避免内存无限增长。

```python
import redis

r = redis.Redis(host='localhost', port=6379, db=0)
r.setex('user:1001', 3600, 'json_profile')
```

## 持久化机制

Redis 提供两种持久化方式：

- **RDB**：在指定时间点生成内存快照，恢复速度快但可能丢失最近数据。
- **AOF**：记录每次写操作日志，数据更安全但文件较大。

生产环境中常将 RDB 和 AOF 结合使用，以兼顾性能和数据安全。
