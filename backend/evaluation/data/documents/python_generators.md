# Python 生成器与迭代器

## 迭代器协议

迭代器是实现了 `__iter__` 和 `__next__` 方法的对象。通过 `next()` 函数可以逐个获取元素，直到抛出 `StopIteration` 异常。列表、元组等可迭代对象可以通过 `iter()` 函数转为迭代器。

## 生成器函数

生成器是一种特殊的迭代器，使用 `yield` 关键字返回数据。与普通函数不同，生成器函数在调用时不会立即执行，而是返回一个生成器对象。每次调用 `next()` 时，函数会从上次暂停的位置继续执行。

```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
```

## 生成器表达式

生成器表达式与列表推导式语法类似，但使用圆括号而不是方括号。它不会一次性生成所有元素，而是按需生成，因此内存占用更低。

```python
squares = (x * x for x in range(1000000))
```

生成器非常适合处理大规模数据流，因为它避免了把所有数据加载到内存中。
